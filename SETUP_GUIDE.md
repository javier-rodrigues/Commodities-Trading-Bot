## PHASE 1: IBKR Paper Trading Setup (Do This First — ~20 min)

### Step 1.1: Open IBKR Paper Trading Account

If you haven't already from the first group project:

1. Go to: https://ndcdyn.interactivebrokers.com/Universal/Application?type=DEMO&code=TRADING_LAB_DIE747858
2. Complete the registration using one group member's info
3. Note your account number (format: `DUOXXXXXX`) — you need this for the report
4. Wait for the confirmation email (usually instant for paper accounts)

### Step 1.2: Install Trader Workstation (TWS)

1. Download TWS from: https://www.interactivebrokers.com/en/trading/tws.php
2. Install and launch TWS
3. Log in with your paper trading credentials
4. Select "Paper Trading" mode when prompted

### Step 1.3: Configure TWS API Settings

This is CRITICAL — the bot cannot connect without these settings:

1. In TWS: **Edit → Global Configuration → API → Settings**
2. Set these exactly:

| Setting | Value |
|---------|-------|
| Enable ActiveX and Socket Clients | ✅ CHECKED |
| Socket port | **7497** |
| Read-Only API | ❌ UNCHECKED |
| Allow connections from localhost only | ✅ CHECKED (for security) |
| Master API client ID | Leave blank |

3. Click **Apply** then **OK**
4. Restart TWS if prompted

### Step 1.4: Verify API Connection

In TWS, check the bottom status bar. It should show "API" with a green indicator.
If you see a firewall prompt, allow TWS through your firewall.

## PHASE 4: First Run — Signal Check (~5 min)

### Step 4.1: Make Sure TWS is Running

- TWS Paper Trading should be open and logged in
- API settings configured per Step 1.3
- Market hours: 9:30 AM – 4:00 PM ET (bot works outside hours but gets delayed data)

### Step 4.2: Run Signal-Only Mode

```bash
python bot.py
```

This will:
1. Connect to TWS on localhost:7497
2. Fetch current prices for SLV, GLD, USO
3. Evaluate entry signals for all 3 strategies
4. Print trade proposals (WITHOUT executing)
5. Disconnect

**Review the output carefully.** You should see:
- Current prices for all 3 underlyings
- Signal evaluation for each strategy (ENTER, HOLD, or EXIT)
- If ENTER signals fire, you'll see specific trade proposals with strikes

### Step 4.3: Adjust Config if Needed

Open `config.py` and adjust:
- **TARGET_EXPIRY**: Verify this expiration date exists in IBKR's option chain.
  In TWS, right-click any of SLV/GLD/USO → "Option Chain" and check available dates.
- **Strike offsets**: The bot approximates ATM strikes. Check the option chain for
  exact available strikes and adjust if needed.
- **Contract quantities**: Scale based on your account size and risk tolerance.

Once you've reviewed the signal output and are satisfied:

4. Save screenshots to `screenshots/` folder with descriptive names

### Step 5.3: First NAV Snapshot

At approximately 3:55 PM ET on Day 1:


- Cumulative return chart (fund vs GLD benchmark)

This checks signals every 15 minutes (configurable in `config.py`).
**Use with caution** — it won't auto-execute unless you also pass `--execute`.

## PHASE 7: Position Management

### Adjusting Positions

If you need to adjust a position mid-period:

1. Close the existing position in TWS manually
2. Record the exit in the trade journal:
   ```python
   from utils.journal import TradeJournal
   j = TradeJournal()
   j.record_exit("trade_id_here", exit_premium=X.XX, realized_pnl=XXX.XX,
                  reflection="Closed early because...")
   ```
3. Open the new/adjusted position (can use bot or TWS directly)
4. Document the deviation from original mandate in your report's reflection section

### Emergency Close All

```bash
python bot.py --close-all
```

This sets the risk manager to liquidation mode. For paper trading, it's usually
easier to just close positions manually in TWS and record exits afterward.

## TROUBLESHOOTING

### "Connection refused" when running bot

- TWS is not running, or API is not enabled
- Check TWS → Edit → Global Config → API → Settings
- Verify port is 7497 (paper) not 7496 (live)

### "No market data" errors

- Paper trading sometimes has delayed/missing data
- Try during market hours (9:30 AM – 4:00 PM ET)
- Check TWS data subscriptions (paper accounts should have free delayed data)

### Option chain not loading

- The TARGET_EXPIRY in config.py might not match available dates
- Check TWS option chain viewer for exact available expirations
- Update config.py to match an available expiry

### Bot hangs or doesn't respond

- TWS may have disconnected — check TWS status bar
- Kill the bot (Ctrl+C) and restart
- Restart TWS if needed

### Streamlit "port already in use"

```bash
streamlit run dashboard.py --server.port 8502
```
